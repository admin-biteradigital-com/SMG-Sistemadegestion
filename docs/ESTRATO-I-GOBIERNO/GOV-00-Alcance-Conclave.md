## 1. Mandato Supremo
El presente documento formaliza la activación del **Conclave de Agentes TI** bajo la autoridad de **Zelmar Tiago Velazquez Borges**. Se establece la transición del proyecto **SMG** hacia el framework **SIGLO (Sistema Integral de Gestión Logística)**.

## 2. Alcance del Proyecto
El alcance se define en dos dimensiones:

### 2.1 Dimensión Funcional (SaaS)
- Gestión de Inventarios (FEFO/Lotes)
- Gestión Comercial (Ventas/Pedidos/Rutas)
- Integración Tributaria (SII Chile)
- Portal de Clientes (Federado)

### 2.2 Dimensión Técnica (Soberanía)
- **Escalabilidad Infinita**: Arquitectura capaz de soportar >1M SKUs y >10M transacciones anuales.
- **Seguridad Zero Trust**: Autenticación centralizada (FreeIPA) y cifrado en reposo.
- **Trazabilidad ALCOA+**: Registro inmutable de cada cambio en código y datos.

## 3. Próximos Pasos (Hoja de Ruta Inmediata)
1.  **Refactorización de Capa de Datos**: Migrar de `SELECT *` a arquitectura paginada y optimizada.
2.  **Validación de Infraestructura**: Asegurar que el backend (Node.js/Postgres) está configurado para alta concurrencia.
3.  **Despliegue de Innovaciones**: Integración con ML para predicción de demanda.
